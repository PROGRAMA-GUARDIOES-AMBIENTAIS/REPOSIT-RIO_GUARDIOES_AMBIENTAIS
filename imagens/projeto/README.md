# imagens — projeto

> acervo visual do programa guardiões ambientais.

## finalidade

armazenar **fotografias, ilustrações e materiais visuais** relacionados à identidade do programa, materiais gráficos e comunicações institucionais.

## origem

fotografias produzidas pela equipe do programa ou por parceiros autorizados.

## nomenclatura

```
AAAA-MM-DD_descricao_NNN.jpg
```

exemplo: `2026-07-31_logo_programa_001.png`.

## metadados obrigatórios

cada arquivo deve estar acompanhado de:

- **autor**;
- **data**;
- **local**;
- **evento**;
- **descrição**;
- **fonte**;
- **licença**.
