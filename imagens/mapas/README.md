# imagens — mapas

> acervo de **mapas** e produtos cartográficos produzidos pelo programa.

## finalidade

armazenar versões **rastreadas** dos mapas temáticos utilizados em relatórios, apresentações e diagnósticos.

## nomenclatura

```
AAAA-MM-DD_municipio_tipo_descricao.png
```

exemplos:

- `2026-07-31_garanhuns_localizacao.png`;
- `2026-07-31_garanhuns_uso_solo.png`;
- `2026-07-31_garanhuns_aterro_ortofoto.tif`.

## metadados obrigatórios

cada mapa deve registrar:

- título;
- autor;
- data de produção;
- sistema de referência (sirgas 2000 preferencial);
- projeção;
- escala / resolução;
- fontes de dados;
- licença.

## fontes de dados utilizadas

- ibge;
- inpe;
- ana;
- osm;
- dados municipais (quando públicos);
- levantamentos próprios.
