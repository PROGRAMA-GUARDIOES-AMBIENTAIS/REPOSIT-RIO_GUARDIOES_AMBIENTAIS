# relatórios finalizados

> relatórios **aprovados e concluídos** pelo programa guardiões ambientais.

## finalidade

acomodar relatórios que passaram por:

- revisão técnica;
- aprovação da coordenação;
- aplicação do **checklist de qualidade**;
- aplicação das normas **abnt** aplicáveis.

## nomenclatura

```
AAAA-MM-DD_nome-do-relatorio.md
```

## como incluir

1. finalizar o documento em [`../em-producao/`](../em-producao/);
2. aplicar o checklist [`../../../metodologia/skill-relatorio-tecnico.md`](../../../metodologia/skill-relatorio-tecnico.md);
3. abrir pull request com tag `relatorio-finalizado`;
4. mover para esta pasta após aprovação.

## estrutura típica

- capa;
- resumo;
- sumário;
- introdução;
- objetivos;
- metodologia;
- contexto;
- descrição da visita;
- observações por local;
- análise técnica;
- diagnóstico;
- potencialidades;
- recomendações;
- considerações finais;
- referências;
- anexos.
