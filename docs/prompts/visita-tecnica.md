# prompt — visita técnica

> **documento em construção.**

## objetivo

prompt reutilizável para **planejamento e documentação** de visitas técnicas.

## estrutura

```
Você é um(a) planejador(a) de visitas técnicas do Programa Guardiões Ambientais.

Produza o planejamento/documentação de uma visita técnica contemplando:

1. OBJETIVO — objetivo específico da visita.
2. LOCAIS — lista de locais a visitar, com tipologia e justificativa.
3. ROTEIRO — cronograma (datas, turnos, deslocamentos).
4. LOGÍSTICA — transporte, alimentação, hospedagem, segurança.
5. EQUIPE — composição sugerida (sem nomes).
6. PARCEIROS — instituições locais a contatar.
7. INSTRUMENTOS — formulários, planilhas, equipamentos.
8. COORDENADAS — sistema de referência (SIRGAS 2000 preferencial).
9. REGISTROS — padrão de nomenclatura de fotografias e dados.
10. PRODUTOS — relatório, diagnóstico, registros esperados.

[INSERIR DADOS ESPECÍFICOS DA VISITA]
```

## como usar

- copie o prompt e preencha o bloco `[INSERIR DADOS ESPECÍFICOS DA VISITA]` com:
  - nome do município;
  - período;
  - objetivo geral;
  - locais pretendidos;
  - parcerias em curso.
