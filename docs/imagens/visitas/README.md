# imagens — visitas

> acervo visual produzido durante as **visitas técnicas** do programa.

## finalidade

armazenar as **fotografias** registradas em campo durante as visitas técnicas.

## nomenclatura

```
AAAA-MM-DD_local_descricao_NNN.jpg
```

exemplos:

- `2026-07-31_garanhuns_aterro_panoramica_001.jpg`;
- `2026-07-31_garanhuns_castainho_reuniao_002.jpg`.

## metadados obrigatórios

cada arquivo deve ter, no mínimo:

- **autor**;
- **data**;
- **local** (município, uf, ponto);
- **evento / visita**;
- **descrição**;
- **fonte** (se externa);
- **licença**;
- **coordenadas** (quando aplicável).

## cuidados

- **fotografias externas** nunca devem ser apresentadas como se fossem produzidas pela equipe;
- ao fotografar pessoas, observar **autorização** prévia e **anonimização** quando necessário;
- preferir **metadados embebidos** (exif);
- armazenar backup externo em caso de arquivos muito grandes.
