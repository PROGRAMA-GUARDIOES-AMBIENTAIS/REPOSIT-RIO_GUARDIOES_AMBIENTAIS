# imagens — infraestrutura

> acervo visual de **infraestrutura ambiental** (aterros, reciclagem, compostagem, sementeiras, parques, equipamentos públicos).

## finalidade

armazenar fotografias e documentos visuais da infraestrutura ambiental visitada ou acompanhada pelo programa.

## nomenclatura

```
AAAA-MM-DD_municipio_tipologia_local_descricao_NNN.jpg
```

exemplo:

- `2026-07-31_garanhuns_aterro_painel_001.jpg`;
- `2026-07-31_garanhuns_sementeira_mudas_002.jpg`.

## metadados obrigatórios

cada arquivo deve ter:

- **autor**;
- **data**;
- **local** (com coordenadas quando aplicável);
- **tipologia** (aterro, parque, etc.);
- **descrição**;
- **fonte**;
- **licença**.
