# 05 — visitas técnicas

> **documento em construção.** documentação das visitas técnicas realizadas pelo programa.

## objetivo

organizar a **memória documental** das visitas técnicas, permitindo consulta, replicação e continuidade do trabalho.

## estrutura de uma visita

cada visita documentada deve conter:

- **readme** — visão geral;
- **roteiro** — cronograma e logística;
- **locais** — lista e descrição;
- **infraestrutura** — equipamentos observados;
- **coordenadas** — dados geográficos;
- **diagnóstico** — análise preliminar;
- **referências** — fontes consultadas;
- **fotografias** — acervo visual.

## nomenclatura de pastas

```
visitas/AAAA/municipio/
```

exemplo: [`../../visitas/2026/garanhuns/`](../../visitas/2026/garanhuns/).

## modelo de visita

exemplo replicável em [`../../visitas/modelo-visita/`](../../visitas/modelo-visita/).

## fluxo

1. planejar visita conforme [`../03_metodologia/metodologia-de-visitas.md`](../03_metodologia/metodologia-de-visitas.md);
2. executar conforme roteiro;
3. documentar conforme [`../03_metodologia/protocolo-de-registro.md`](../03_metodologia/protocolo-de-registro.md);
4. produzir relatório conforme [`../../metodologia/skill-relatorio-tecnico.md`](../../metodologia/skill-relatorio-tecnico.md);
5. arquivar em [`../../visitas/`](../../visitas/).
