# 05 — governança do repositório

> documento em construção. nomes de responsáveis não são criados sem validação institucional.

## princípios

a governança deste repositório baseia-se em:

- **transparência**;
- **rastreabilidade**;
- **controle de versões**;
- **revisão por pares**;
- **separação entre informação e interpretação**.

## quem pode propor alterações

- coordenação do programa;
- guardiões ambientais designados;
- parceiros institucionais;
- pesquisadores e extensionistas convidados.

> nomes específicos serão definidos em [`CONTRIBUTING.md`](../CONTRIBUTING.md) quando validados pela coordenação.

## como documentos são revisados

1. qualquer alteração passa por **pull request**;
2. o template de pr inclui **checklist** de qualidade;
3. ao menos **uma revisão** antes do merge;
4. mudanças em arquivos de governança, metodologia ou referências exigem **revisão adicional**.

## como relatórios são aprovados

- relatórios seguem metodologia [`../metodologia/skill-relatorio-tecnico.md`](../metodologia/skill-relatorio-tecnico.md);
- passam por **checklist de qualidade** (conteúdo, fontes, imagens, técnico);
- são revisados antes de serem movidos para `relatorios/finalizados/`.

## como versões são controladas

- **branches** descritivas por mudança;
- **commits** com prefixos (`docs:`, `feat:`, `fix:`, `refactor:`, `chore:`);
- **tags** para marcos do projeto (ex.: `v1.0`, `v1.1`);
- **changelog** atualizado a cada release.

## como informações devem ser citadas

sempre indicar:

- **fonte** (documento, pessoa, site, lei);
- **data**;
- **autor** (quando aplicável);
- **link ou caminho** para o material original;
- **licença** de uso.

## como fontes devem ser registradas

- padrão **abnt** (nbr 6023);
- arquivo [`../08_referencias/bibliografia.md`](../08_referencias/bibliografia.md) é a fonte única de referências formais;
- citações inline seguem nbr 10520.
