# 04 — relatórios

> **documento em construção.** diretório de documentação sobre os relatórios produzidos pelo programa.

## tipos de relatórios

- **relatórios técnicos de visita**;
- **diagnósticos territoriais**;
- **relatórios institucionais**;
- **relatórios de atividades**;
- **relatórios de projetos**;
- **relatórios de parcerias**.

## estrutura típica

cada relatório deve conter:

1. identificação (título, data, local, equipe);
2. objetivo;
3. contexto;
4. metodologia;
5. resultados / observações;
6. diagnóstico;
7. potencialidades;
8. recomendações;
9. referências;
10. anexos (fotos, mapas, dados).

## nomenclatura

```
AAAA-MM-DD_nome-do-relatorio.md
```

exemplos:

- `2026-07-31_relatorio-visita-garanhuns.md`
- `2026-08-15_diagnostico-territorial-garanhuns.md`
